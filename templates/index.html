🔍 Bảng Giải Mã Luồng Dữ Liệu & Câu Lệnh Code (Từng Chương)

Backend: Flask · Jinja2 · SQLite

Bảng tổng hợp chi tiết cơ chế hoạt động của toàn bộ dự án: Lấy dữ liệu ở đâu, Dùng lệnh gì để lấy, Xử lý dữ liệu ra sao và Truyền về giao diện (Template) bằng cách nào.

Công đoạn Câu lệnh / Cú pháp trong code Ý nghĩa & Dữ liệu nhận/truyền
1. Nguồn dữ liệu STUDENTS_DICT (In-memory) Dữ liệu lưu tạm trong RAM dưới dạng Dictionary đa cấp lồng nhau (Key là MSSV, Value là thông tin & điểm số).
2. Lấy dữ liệu lọc request.args.get("lop", "") Lấy dữ liệu từ URL Query String: Đọc tham số sau dấu hỏi chấm trên trình duyệt (Ví dụ: /sodiem?lop=K47A sẽ lấy được chuỗi "K47A").
3. Lấy dữ liệu động @app.route("/sodiem/<mssv>") URL Dynamic Converter: Bắt trực tiếp giá trị trên đường dẫn (VD: /sodiem/23T1020001 ➔ truyền thẳng biến mssv="23T1020001" vào hàm Python).
4. Cách truyền dữ liệu render_template("sodiem.html", students=..., ds_lop=...) Truyền danh sách sinh viên đã lọc và danh sách các lớp sang file Jinja2 HTML để hiển thị vòng lặp for.
5. Xuất REST API jsonify(STUDENTS_DICT) Chuyển đổi Dict của Python thành chuỗi định dạng chuẩn JSON và gắn Header Content-Type: application/json.

Công đoạn Câu lệnh / Cú pháp trong code Ý nghĩa & Dữ liệu nhận/truyền
1. Bắt phương thức if request.method == "POST": Phân biệt người dùng mới mở trang (GET) hay người dùng bấm nút Gửi dữ liệu form (POST).
2. Lấy dữ liệu ô nhập request.form.get("height")
request.form.get("a")		 Lấy dữ liệu từ thẻ input: Lấy chuỗi người dùng gõ trong thẻ <input name="height"> gửi lên từ Request Payload.
3. Làm sạch & Ép kiểu .replace(",", ".")
float(height_val)		 Chuẩn hóa dấu phẩy Việt Nam thành dấu chấm thập phân, ép từ kiểu str sang kiểu số thực float để tính toán.
4. Kiểm tra hợp lệ (Validation) try ... except (ValueError, TypeError):
if not (50 <= h <= 250):		 Bảo vệ hệ thống: Bắt lỗi nếu người dùng nhập chữ, hoặc nhập số âm, số đo không thực tế để gán biến error.
5. Truyền kết quả & Màu render_template("bmi.html", result=..., error=...) Gói kết quả tính, phân loại và biến màu sắc (danger/success/warning) gửi sang Jinja2 để đổi màu banner.

Công đoạn Câu lệnh / Cú pháp trong code Ý nghĩa & Dữ liệu nhận/truyền
1. Kết nối CSDL sqlite3.connect(DB_FILE)
conn.row_factory = sqlite3.Row		 Mở file demo.db. Thiết lập Row giúp truy xuất cột theo tên như Dict (VD: row["name"] thay vì vị trí số 0, 1).
2. Thống kê tổng hợp SELECT COUNT(*), AVG(gpa), MAX(gpa), MIN(gpa) Hàm tổng hợp SQL tính toán tức thì trên toàn bảng, lấy kết quả 1 dòng bằng lệnh cursor.fetchone().
3. Tìm kiếm & Lọc an toàn WHERE name LIKE ?
params.append(f"%{search}%")		 Parameterized Query (Dấu hỏi chấm ?): Ngăn chặn 100% tấn công tiêm mã độc SQL Injection.
4. Ghi/Xóa dữ liệu (CRUD) INSERT INTO students ...
conn.commit()		 Thực thi câu lệnh thêm/sửa/xóa và gọi commit() để lưu vĩnh viễn thay đổi vào ổ cứng.
5. Điều hướng & Flash flash("Thêm thành công!", "success")
redirect(url_for('students_sql'))		 Áp dụng mô hình PRG (Post/Redirect/Get): Thông báo pop-up rồi chuyển hướng để người dùng F5 không bị gửi lặp dữ liệu.

Công đoạn Câu lệnh / Cú pháp trong code Ý nghĩa & Dữ liệu nhận/truyền
1. Khai báo Form class RegisterForm(FlaskForm):
validators=[DataRequired(), Email()]		 Định nghĩa cấu trúc form bằng hướng đối tượng OOP, tự động kiểm tra rỗng, đúng dạng email và độ dài mật khẩu.
2. Chống giả mạo CSRF {{ form.hidden_tag() }} Sinh ra một thẻ input ẩn chứa mã Token băm bảo mật. Nếu kẻ gian tạo form từ trang web khác gửi tới sẽ bị chặn đứng.
3. Lưu trạng thái đăng nhập session["username"] = user["username"]
session.permanent = True		 Flask Session: Dữ liệu đăng nhập được mã hóa và lưu vào Cookie trình duyệt bằng chữ ký bí mật app.secret_key (tồn tại 7 ngày).
4. Kiểm tra phiên (Auth Guard) if "username" not in session:
return redirect(url_for("login"))		 Bảo vệ trang /profile: Nếu chưa đăng nhập thì chặn lại và đẩy về trang đăng nhập.
5. Đăng xuất session.pop("username", None) Xóa biến đăng nhập khỏi session cookie, đưa tài khoản về trạng thái khách (Guest).

2. Nạp dữ liệu tự động @app.context_processor
def inject_global_data():		 Tự động bơm các biến site_title, current_year vào tất cả các file HTML mà không cần phải truyền thủ công ở từng route.
